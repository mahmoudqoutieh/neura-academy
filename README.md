# أكاديمية نيورا: صفحة الهبوط

موقع ثابت (HTML وCSS وJavaScript) مع ملف PHP واحد لنموذج التسجيل.
يعمل على أي باقة استضافة مواقع في Hostinger، ولا يحتاج Node.js ولا أي خطوة بناء.

## محتوى المستودع

| المسار | الوظيفة |
|---|---|
| `index.html` | الصفحة كاملة |
| `assets/css/style.css` | التصميم (الكمبيوتر والهاتف) |
| `assets/js/main.js` | الفيلم الذي يتحرك مع التمرير، وتأثيرات الماوس، وإرسال النموذج |
| `assets/video/` | مقاطع الفيلم للكمبيوتر والهاتف وصورها الأولى |
| `assets/img/` | الصور والشعار وصورة المشاركة |
| `api/enroll.php` | يستقبل طلب التسجيل ويحفظه في MySQL ويرسل لك بريداً |
| `api/config.sample.php` | نموذج ملف الإعدادات (انسخه، لا تعدّله هنا) |
| `database/schema.sql` | جدول قاعدة البيانات |
| `.htaccess` | HTTPS، والتخزين المؤقت، والضغط، وحماية الملفات |

## النشر على Hostinger (مرة واحدة)

### 1. ربط المستودع
1. في hPanel افتح موقعك، ثم **Advanced > Git**.
2. المستودع خاص، لذلك انسخ **SSH key** الظاهر في الصفحة وأضفه في GitHub:
   المستودع > **Settings > Deploy keys > Add deploy key** (القراءة فقط تكفي).
3. في Hostinger اكتب:
   - Repository: `git@github.com:mahmoudqoutieh/neura-academy.git`
   - Branch: `main`
   - Directory: اتركه فارغاً لينشر داخل `public_html`
   ملاحظة: يجب أن يكون `public_html` فارغاً قبل أول نشر (احذف ملف `default.php` إن وُجد).
4. اضغط **Create** ثم **Deploy**.
5. اختياري: فعّل **Auto Deployment** وأضف رابط الـ Webhook في GitHub
   (Settings > Webhooks) لينشر الموقع تلقائياً بعد كل تعديل.

### 2. قاعدة البيانات
1. hPanel > **Databases > MySQL Databases**: أنشئ قاعدة بيانات ومستخدماً واحفظ كلمة المرور.
2. افتح **phpMyAdmin**، اختر القاعدة، ثم تبويب **SQL**، والصق محتوى `database/schema.sql` واضغط **Go**.

### 3. ملف الإعدادات (كلمات المرور لا تُرفع إلى GitHub أبداً)
1. hPanel > **File Manager**.
2. الطريقة الأكثر أماناً: أنشئ ملفاً باسم `neura-config.php` في المجلد **فوق** `public_html` مباشرة
   (المجلد الذي يحتوي `public_html`).
   أو بديلاً: أنشئه داخل `public_html/api/` باسم `config.php`.
3. الصق فيه محتوى `api/config.sample.php` وغيّر القيم:
   - بيانات قاعدة البيانات من الخطوة 2.
   - `notify_to`: بريدك الذي تصلك عليه الطلبات.
   - `mail_from`: بريد على نطاقك نفسه (أنشئه من hPanel > Emails)، مثل `no-reply@نطاقك`.
   - `ip_salt`: أي نص طويل عشوائي.

### 4. شهادة الأمان SSL
hPanel > **Security > SSL**: فعّل الشهادة المجانية. ملف `.htaccess` يحوّل الزوار تلقائياً إلى `https`.

### 5. التجربة
افتح موقعك، وأرسل طلب تسجيل تجريبياً، وتأكد من:
- ظهور رسالة «وصلنا طلبك».
- وصول الطلب إلى جدول `enrollments` في phpMyAdmin.
- وصول البريد إلى `notify_to` (إذا ذهب للبريد المزعج، أضف `mail_from` إلى جهات الاتصال).

## قبل الإطلاق: عدّل هذه المعلومات
- **الأسعار** في قسم الخطط داخل `index.html`: `39$` و`299$` (أسعار مقترحة).
- **بريد التواصل** `hello@neura-academy.com` يظهر في `index.html` ثلاث مرات (ابحث عنه واستبدله).
- **صورة المشاركة**: بعد ربط النطاق، غيّر `og:image` و`twitter:image` في `index.html`
  إلى رابط كامل، مثل `https://نطاقك/assets/img/og.jpg`، لتظهر الصورة عند مشاركة الرابط.

## بعد أي تعديل على CSS أو JS
الملفات مخزنة مؤقتاً لمدة سنة لتسريع الموقع. بعد تعديل `style.css` أو `main.js`
غيّر رقم الإصدار في `index.html` (مثلاً `?v=1` إلى `?v=2`) حتى يرى الزوار التعديل فوراً.

## عرض طلبات التسجيل
من phpMyAdmin: افتح قاعدة البيانات ثم جدول `enrollments`. يمكنك تصديره إلى Excel من تبويب **Export** (صيغة CSV).
